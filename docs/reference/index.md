# API Reference

Every module under `scripts/`, `dashboard/`, and the FreqTrade `user_data` tree
(`strategies/`, `scripts/`, `freqaimodels/`), regenerated from the code's own docstrings on
every build. Use the sidebar to browse by directory, or the search bar for a specific function.

See [Documentation Coverage](../coverage.md) for which functions still need a docstring written,
and [Contributing](../contributing.md) for how to write one that renders well here.
