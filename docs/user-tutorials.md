# User-Facing Tutorials — ScribeHow Setup (manual step)

**This step needs you, not me.** Creating accounts on third-party services is outside what I do
automatically — you'll need to sign up yourself.

## What to do

1. Go to [scribehow.com](https://scribehow.com) and create an account (free tier covers this
   scale).
2. Install their browser extension.
3. Click "Record" before doing any workflow you want documented (e.g. "connect your exchange API
   key," "read your dashboard," "set your risk limits") — it auto-captures each click/step with
   screenshots and writes the instructions for you.
4. Export as a shareable link or embed it in the customer panel once it exists (Phase 3 of the
   platform roadmap).

## What to record, once the flows exist

- Account signup and first login
- Connecting an exchange API key (once Phase 3's key-management flow ships)
- Reading the dashboard: what each stat means, how to interpret P&L
- Setting risk limits / pausing your own account
- Revoking an API key

Nothing here needs building right now — most of these flows don't exist yet (they're part of
Phase 3). This page is a placeholder reminder for when they do.
