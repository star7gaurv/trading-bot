# The Self-Evolution Workflow

This workflow ensures that every time Antigravity interacts with the FinBuddy workspace, the conscious memory of the project is strictly maintained and self-evolved.

## Step 1: Memory Ingestion (Read)
Execute the following commands or file views to load the conscious state:
1. View `finbuddy_memory/FINBUDDY_PROJECT_MEMORY.md` to understand the current phase and components.
2. View `finbuddy_memory/CONTEXT.md` to ingest the latest global market regime.
3. View `CLAUDE.md` to read the historical failures and session history.

## Step 2: Intelligent Analysis & Execution
When modifying strategies (e.g., `FinBuddyFreqAI.py`):
1. **Never apply static rules.** If a problem is found, design an adaptive, ML-based, or logic-based dynamic solution.
2. Ensure any new logic evaluates per-candle data rather than imposing global caps.
3. Use precision file editing tools (`replace_file_content`) to inject intelligence into the code without rewriting entire files unnecessarily.

## Step 3: Memory Synchronization (Write)
Before completing your task:
1. Append your actions, the root cause of any bug, and the rationale for your solution into the "Session History Summary" of `CLAUDE.md`.
2. Update the "Current State" and "Phase Roadmap" in `finbuddy_memory/FINBUDDY_PROJECT_MEMORY.md`.
3. If new strategies or concepts were discovered, add an entry to `finbuddy_memory/session_events.md`.

## Step 4: System Commit
Once the memory is synchronized and the code is written:
1. Add all modified files.
2. Commit the changes to the Git repository with a highly descriptive message detailing the intelligence added.
3. Restart the trading engine container (`docker restart freqtrade`) to immediately boot the new consciousness.
